# Knowte Web Companion

Start Knowte and open **Config → Knowte Web Companion**. Select **Copy
extension path**, then use that path when the browser asks for the unpacked
extension folder. In the native folder picker, press `⌘⇧G` on macOS or
`Ctrl+L` on Windows/Linux, paste the path, and confirm the folder.

- Chromium: open `chrome://extensions`, enable Developer mode, and choose **Load unpacked**.
- Firefox: open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select `manifest.json` in the copied path.

Generate a pairing key in Knowte and enter it in the extension within five
minutes.

Select text and press `Alt+Shift+K`, or press `Alt+Shift+X` and drag a visible
region. The on-page editor saves directly to the Library and optional Artifact,
with Tags and an Annotation, without leaving the original page. **Save page**
stores the page as a Source without creating Evidence.
